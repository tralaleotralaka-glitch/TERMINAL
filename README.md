# Терминал для телефона

Автономный мини-терминал в одном окне: оболочка, виртуальная файловая система
и встроенный справочник **ровно из 500 команд**, который открывается кнопкой
**«?» в правом верхнем углу**. Никаких ссылок, запросов в сеть и внешних
библиотек — всё работает локально в браузере телефона.

## Скачать APK (Android)

Готовый файл лежит в релизе и обновляется автоматически при каждом изменении:

**https://github.com/tralaleotralaka-glitch/TERMINAL/releases/tag/apk**

Установка: откройте страницу релиза на телефоне → скачайте `terminal-*.apk` →
откройте файл и разрешите установку из этого источника (Android спросит
один раз). Приложение работает полностью офлайн: ни интернета, ни ссылок,
ни разрешений оно не запрашивает.

Сборка: `.github/workflows/android.yml` собирает APK на каждый push
(Gradle + Android SDK), проверяет, что внутри ровно 500 команд, кладёт файл
в артефакты и в релиз с тегом `apk`.

## Запуск в браузере

Просто откройте `index.html` — или поднимите статический сервер:

```sh
python3 serve.py          # http://localhost:8000
```

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка экрана, строка ввода, шторка справочника |
| `styles.css` | мобильная тёмная тема, безопасные зоны, клавиатурные клавиши |
| `app.js` | оболочка, файловая система, 60+ встроенных команд, справочник |
| `commands.js` | каталог 500 команд (генерируется) |
| `tools/gen_commands.py` | генератор каталога, проверяет уникальность и число = 500 |
| `serve.py` | необязательный статический сервер для предпросмотра |
| `android/` | нативный проект-обёртка на WebView (без зависимостей, без сети) |
| `tools/sync_assets.py` | копирует веб-файлы в `android/app/src/main/assets` |
| `tools/check_apk.py` | проверяет собранный APK: assets на месте, внутри 500 команд |
| `.github/workflows/android.yml` | CI: сборка APK и публикация в релиз `apk` |

## Управление

- **?** в правом верхнем углу — справочник на 500 команд с поиском и категориями.
- Нажатие на команду в справочнике вставляет её в строку ввода.
- `↑` `↓` — история команд, `Tab` — автодополнение имён команд и путей.
- Нижний ряд клавиш: `Tab`, `Esc`, `Ctrl C`, стрелки и частые символы.

## Встроенные команды песочницы

`ls cd pwd cat touch mkdir rm cp mv tree find grep wc head tail sort uniq base64
du df free ps top kill date uname uptime whoami id hostname neofetch fortune
cowsay banner figlet seq shuf history env export which man tldr calc bc expr
echo clear help` и другие (`help` покажет полный список).

Остальные команды из каталога доступны как справка: `man <команда>`,
`tldr <команда>`, `?`.
